# Code taken from other projects

tam-data is written fresh in C11 on libtam. This file lists every piece
of code taken from another project, with where it came from, what
changed, and why it earned its place. Ideas taken without code go in
`ideas/` instead.

## Pieces taken

None. VisiData is an ideas source, recorded in `ideas/visidata.md`; no
VisiData code is carried here. libtam is our own library, linked
statically, and needs no notice here.

When code is taken, add a row here and the project's notice to
COPYRIGHT in the same change. Licences matter: tam-data is
GPL-3.0-or-later, so code under a GPL v2-only licence cannot be carried.
